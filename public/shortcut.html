Save recipes to Apple Notes from the Share Sheet

Apple Notes has no public API, so a tiny iOS Shortcut does the last step. Install it below, and from then on saving a recipe is one tap from Instagram, TikTok, or Safari.

Get the Shortcut

On your iPhone: tap the button, open the downloaded file, and tap Add Shortcut. That's the whole setup — the recipe appears in Apple Notes whenever you share a link to Save Recipe.

Required · connect your account

Add your personal token

Recipes are private to your account, so the Shortcut has to prove it's you. Open your Account page, copy your Shortcut token, then in the Shortcut's Get Contents of URL action add a Header:

  • Key: Authorization
  • Value: Bearer <your token>

Without this header the site replies "Sign in to save recipes" instead of a note. Keep the token secret — anyone with it can save to your account.

Prefer to build it by hand? The 5 steps
  1. 1

    Create the shortcut

    Open the Shortcuts app → tap + → rename it to Save Recipe.

  2. 2

    Show it in the Share Sheet

    Tap the info button (i) → enable Show in Share Sheet. Set the input type to URLs.

    On newer iOS this appears as "Receive URLs input from Share Sheet". Keep it to URLs — sharing a reel sends its link, which is exactly what this shortcut posts. (To save a recipe you've copied as text, open the website in Safari and use its paste box instead.)

  3. 3

    Call this site

    Add the action Get Contents of URL, then tap the ⌄ ("Show More") to reveal all its options and set:

    • URL: https://this-site/api/extract
    • Method: POST
    • Header Authorization = Bearer <your token> (copy the token from your Account page)
    • Request Body: JSON
    • Add field url (Text) = Shortcut Input
  4. 4

    Pull out the note

    Add the action Get Dictionary Value → Key = noteText → from Contents of URL.

  5. 5

    Save to Notes — or show why not

    Add an If action → condition: Dictionary Value (the noteText) has any value.

    • If → Create Note (Notes app), Body = Dictionary Value. Pick a folder like Recipes and turn off Show Compose Sheet so it saves automatically.
    • Otherwise → Get Dictionary Value (Key message, from Contents of URL) → then Show Result to display it.

    Why the If: when a reel has no written recipe the site replies with an explanation instead of a note. Get Contents of URL keeps going on that reply (it only stops on a real network error), so this branch is what surfaces the message instead of saving a blank note.

  6. 6

    Done — try it

    In Instagram or TikTok: tap Share → Save Recipe. The note appears in Notes with tappable timers and a shopping-list link.

Optional · recommended

Save from a screenshot

For recipes that live in the comments or as on-screen text in the video: take a screenshot, then share the screenshot to a second shortcut. Create one named Save Recipe Photo:

  1. Info (i) → Show in Share Sheet → input type Images.
  2. Action Convert Image → to JPEG (shrinks the upload).
  3. Action Base64 Encode → input = Converted Image.
  4. Action Get Contents of URL → same setup as step 3 above, but the JSON field is image (Text) = Base64 Encoded.
  5. Then the same Get Dictionary Value → If → Create Note ending as steps 4–5.

Works for anything readable: comment recipes, on-screen captions, cookbook pages, even handwriting.

Recipe longer than one screen? Take several screenshots, select them all in Photos → Share → Save Recipe Photo, and add a Combine Images action (Vertically) as the first step of the shortcut — they merge into one tall image before upload. On the website, just select all the screenshots at once; it combines them for you.

Optional · zero-effort mode

Double-tap the back of your phone

Skip even the manual screenshot: let the shortcut take it for you. Create a shortcut named Snap Recipe:

  1. Action Take Screenshot (captures whatever is on screen).
  2. Action Convert Image → to JPEG.
  3. Action Base64 Encode → input = Converted Image.
  4. Action Get Contents of URL → same POST setup, JSON field image = Base64 Encoded.
  5. Same Get Dictionary Value → If → Create Note ending.

Then wire it to a gesture: Settings → Accessibility → Touch → Back Tap → Double Tap → Snap Recipe.

Usage: scroll until the recipe (comment or on-screen text) is visible → double-tap the back of your iPhone → the note appears in Notes. That's the whole flow.

Optional

Ask for servings

Want the note scaled to your table? Insert an Ask for Input action (type Number, prompt How many servings?) before step 3, then add a second JSON field in Get Contents of URL: servings (type Number) = Provided Input.

Tip

The same shortcut works from Safari on any recipe website — and you can test it right now by sharing any food-blog URL to Save Recipe.
